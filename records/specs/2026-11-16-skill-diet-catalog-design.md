# Skill catalogue description diet

Shorten only the discovery description in 26 skills. Preserve all other source
bytes, including names, invocability, judgement seams and runtime bodies. The
three already-qualified skills, pending thematic body slice, jot and prep are excluded.

## Scope and acceptance

Freeze 35 discovery requests covering all 32 installed skills and the original
catalogue before authoring. Measure five baseline and five candidate samples,
with identical initial guidance, full catalogue reading and strict native tool
audits. Require every candidate selection to match the intended skill. Keep all
baseline failures. No body execution or workflow parity is inferred from these
selection decisions.

`catalog-source-bindings.json` records every original file and its hash after
removing only the description line. Verify the corresponding candidate hash
before committing. Review each new description against the old selection
boundaries; retain operational detail in the byte-identical body. Measure actual
source bytes and estimated tokens per file; keep catalogue payload separately.
Evidence and frozen acceptance live under
`verification/experiments/2026-11-16-skill-diet/`. V2 qualifies 175/175 discovery decisions per arm, with all ten native audits passing. V1 returned the wrong overlapping entry choice once; jot and prep descriptions were restored verbatim before v2. No v1 candidate sample is pooled with v2.
