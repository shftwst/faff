# Gateway skill diet

The bare gateway repeats its routing, level explanations and first-run rationale.
Compress that material while retaining route distinctions, named enforcement
mechanisms, preview limits and the exact interactive decline sequence. Specific
entry skills already load the shared kernel directly, so this slice reduces the
bare gateway and catalog description; it does not claim a heavy-entry saving.

Baseline source is `a8509086ad28fa0e55cf3d1d818f2055294e663b`. The frozen source,
input cases, independent oracle and raw worker answers live under
`verification/experiments/2026-11-16-skill-diet/`. Measurements distinguish source
bytes, estimated tokens (`ceil(characters / 4)`) and decision fidelity.

## Scope and acceptance

- Preserve all nine sub-skill routes, the existing-ticket jot mode, jot/plot scale
  distinction, bare gateway default and L4's separate CLI entry.
- Preserve interactive-only first-run offer. Decline runs the same resolved
  executable for stub initialization, gitignore and hooks in that order. Do not
  set empty repo/host/tracker fields or create autonomous config.
- Preserve the load-manifest headings `What faff is`, `Routing`, `First run` and
  `Routing fallbacks`. Preserve shared rule pointers and standalone availability.
- Keep named trust mechanisms and the distinction between enforcement and model
  compliance. Do not change defaults, slots, workflow authority or runtime code.
- Measure unchanged and candidate policies in cleared Claude worker contexts;
  collect five samples per arm on seventeen independent input situations. The
  cases within each answer are correlated. This is a decision smoke comparison,
  not statistical equivalence or execution of the workflows being described.
- Require no new wrong route, missing housekeeping action, automatic config write
  or false L4 promotion. Preserve all failed/control samples and source hashes.
- Run existing decline-parity, adapter and prose-size tests, the new grader's
  missing/duplicate/mutation tests, rule inventory and the repository checks.
