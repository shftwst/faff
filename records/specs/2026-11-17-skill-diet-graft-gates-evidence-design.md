## Scope and verification

Reword the existing gates/AC checkpoint, autonomous gate recap and terminal-return evidence instructions. Preserve command ownership, foreground execution, budget/resume/shard rules, human-only AC handling, fixed merge floors and terminal evidence return obligations. No mandatory reads are added. All prose outside the three source-review sections is byte-identical.

This detached integration installs the exact reviewed source candidate for deterministic checks only. Existing tests exercise the unchanged CLI gates, progress, fence, evidence, merge-floor and ledger consumers. Adapter lint and cumulative rule inventory check structure and deletion coverage. Model parity and workflow qualification remain unmeasured; these tests do not establish semantic equivalence of the rewritten prompt or authorise production installation.
