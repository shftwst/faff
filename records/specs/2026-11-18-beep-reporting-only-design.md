# Reporting prompt reduction

Apply only five previously reviewed reporting replacements. Ledger bookkeeping and current main changes stay untouched. Canonical summary storage, authority, buckets, economics, rendering and publication order remain required. Existing real run-summary and consumer tests cover deterministic behavior; intended-driver candidate evidence is pending. No hosted publication or whole-workflow qualification is claimed.
