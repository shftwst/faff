## Measurement boundary

- Produce actual ledger augmentation from supplied build returns, review/post-merge artifacts, prep holds and discovered-ticket acknowledgements. Run real `runcheck` and summary consumers against the persisted result.
- Retain an admitted issue without a terminal observation in an incomplete case. Prep holds, annotations, details and new-ticket counts must not satisfy completeness.
- Emit actual phase events with closing-only token flags, exact pinned root/session, CLI-owned envelope/hash and gate/rework fields. Include a micro-action that must not emit an event, multiple transcript checkpoints and a missing-transcript case.
- Ask bounded decisions for the annotation distinctions and writers. Model inputs contain observations, never the target ledger or private oracle.
- Preserve strict native audits, raw failures, independent actual-output reading and five samples per arm. Freeze fixture, policies, gates and source hashes before any model call.

Real open/record/heartbeat/close and refusal behaviour has a separate deterministic feasibility preflight. It does not qualify model behaviour, summary production or token/quality events. Governance/owner branches outside the changed sections remain unchanged and outside the model claim.

If the separate Reporting cut is accepted first, rebuild both ledger comparison policies from that accepted source and change only these two ledger/event sections. Never install this whole-file draft over a later accepted Reporting change.
