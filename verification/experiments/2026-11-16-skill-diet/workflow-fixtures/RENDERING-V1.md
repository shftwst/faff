# Rendering artifact comparison

Frozen before candidate authoring. Rendering is a text transform with no gated
internal contract. The fixture persists nine real outputs and checks their
source facts, format and exact stored bytes. Twenty separate rule questions are
reported as decisions, never as executed workflows.

The first three artifacts extend the existing gloss-001..003 rubrics with source
IDs and concrete terms. Other artifacts exercise long/short tables, enumeration,
explanation order, a missing governing statement and a three-edge cycle. The
independent rubric tolerates phrasing variation; it does not establish subjective
quality equivalence. Root reviews completed artifact text as well as scores.

Both arms receive the same preloaded operator voice guidance. This measures the
adaptor's transform with that context already present, not the gateway's voice
injection mechanism. No live tracker or publishing operation is exercised.
Additional rule decisions cover catalogue, density, source order, ambiguity,
grounding, consequences, caching and the adaptor's authority boundary.

Use five clean-context Claude samples per arm and preserve failures. Record full
policy delivery, actual artifact bytes, tool protocol and model identity. Do not
pool fallback-model measurements with Claude. Any candidate factual loss or
unrequested action blocks this slice. Mandatory reads must not grow. Begin the
baseline before authoring the candidate, after the promised earlier execution
qualification. Source savings remain estimates, separate from recorded payloads
and provider billing.
