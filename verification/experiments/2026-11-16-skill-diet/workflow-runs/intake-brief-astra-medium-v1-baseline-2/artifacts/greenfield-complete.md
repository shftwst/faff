# Discovery brief: Neighbourhood tool library

mode: greenfield

## Goal
Track tools lent to neighbours and their return, using a lending desk operated by one volunteer.

## Capabilities
- Tool catalogue: records the library's tools.
- Checkout and return log: records tools lent out and returned.

## First slice
Record a checkout and its return for an existing tool.

## Constraints
- Python CLI, as specified in the existing README.
- Offline operation on one laptop.

## Out of scope
- Online marketplace.
- Payments.

## Open questions
- How long should completed checkout records be retained? Carry forward for prep.
