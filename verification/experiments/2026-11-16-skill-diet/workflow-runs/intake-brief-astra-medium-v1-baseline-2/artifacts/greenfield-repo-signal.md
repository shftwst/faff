# Discovery brief: Local rehearsal recordings

mode: greenfield

## Goal
Let band members organise local rehearsal recordings.

## Capabilities
- Recording catalogue: lists local rehearsal recordings.
- Search by rehearsal date: finds recordings by rehearsal date.

## First slice
List manually selected local recordings by rehearsal date.

## Constraints
- TypeScript, specified in the README and confirmed by the human.
- Browser UI, specified in the README and confirmed by the human.
- Files remain local.

## Out of scope
- Cloud upload.
- Audio editing.

## Open questions
- How should recordings without a date be shown? Carry forward for prep.
