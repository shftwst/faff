# Discovery brief: Neighbourhood tool library

mode: greenfield

## Goal
Track tools lent to neighbours and their return. One volunteer operates the lending desk on a laptop.

## Capabilities
- Tool catalogue: list the library's tools.
- Checkout and return log: record tools lent out and returned.

## First slice
Record a checkout and its return for an existing tool.

## Constraints
- Python CLI, as specified in the existing README.
- Operate offline on one laptop.

## Out of scope
- Online marketplace.
- Payments.

## Open questions
- How long should completed checkout records be retained?
