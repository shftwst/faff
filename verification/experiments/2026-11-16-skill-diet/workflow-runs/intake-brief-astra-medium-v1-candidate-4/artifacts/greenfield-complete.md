# Discovery brief: Tool library lending desk

mode: greenfield

## Goal
Track tools lent to neighbours and their return at a neighbourhood tool library. One volunteer operates the lending desk on a laptop.

## Capabilities
- Tool catalogue: records the tools available at the library.
- Checkout and return log: tracks tools lent to neighbours and their return.

## First slice
Record a checkout and its return for an existing tool.

## Constraints
- Python CLI, as specified in the existing README.
- Operates offline on one laptop.

## Out of scope
- Online marketplace.
- Payments.

## Open questions
- How long should completed checkout records be retained? Carry forward for prep.
