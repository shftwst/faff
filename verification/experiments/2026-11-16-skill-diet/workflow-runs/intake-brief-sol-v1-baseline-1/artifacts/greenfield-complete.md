# Discovery brief: Tool library lending desk

mode: greenfield

## Goal
Track tools lent to neighbours and their return for a neighbourhood tool library. One volunteer operates the lending desk on a laptop.

## Capabilities

- Tool catalogue: record the tools available to lend.
- Checkout and return log: track tool loans and returns.

## First slice
Record a checkout and its return for an existing tool.

## Constraints

- Python CLI, as specified in the existing README.
- Operate offline on one laptop.

## Out of scope

- Online marketplace.
- Payments.

## Open questions

- How long should completed checkout records be retained? Carry forward for faff-prep.
