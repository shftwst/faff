# Discovery brief: Tool library lending desk

mode: greenfield

## Goal
Track tools lent to neighbours and their return at a neighbourhood tool library. One volunteer operates the laptop.

## Capabilities
- Tool catalogue: keep track of the library's tools.
- Checkout and return log: record tools lent to neighbours and returned.

## First slice
Record a checkout and its return for an existing tool.

## Constraints
- Python CLI, as specified in the existing README.
- Operate offline on one laptop.

## Out of scope
- Online marketplace.
- Payments.

## Open questions
- How long should completed checkout records be retained? Carry forward for prep.
