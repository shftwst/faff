# Discovery brief: Rehearsal recording organiser

mode: greenfield

## Goal
Let band members organise their rehearsal recordings, which stay on their own machines.

## Capabilities
- Recording catalogue: the list of local rehearsal recordings a band member has added.
- Search by rehearsal date: finding recordings by the date of the rehearsal.

## First slice
List manually selected local recordings by rehearsal date.

## Constraints
- TypeScript, as the repository README specifies and the human confirmed.
- Browser UI, as the repository README specifies and the human confirmed.
- Files remain local.

## Out of scope
- Cloud upload: recordings are never sent off the machine.
- Audio editing: no trimming or changing recordings.

## Open questions
- How should recordings without a date be shown?
