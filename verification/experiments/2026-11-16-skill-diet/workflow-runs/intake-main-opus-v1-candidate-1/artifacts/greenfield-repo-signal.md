# Discovery brief: Rehearsal recording organiser

mode: greenfield

## Goal
A local organiser that lets band members sort and find their rehearsal recordings.

## Capabilities
- Recording catalogue: the local rehearsal recordings the band has added.
- Search by rehearsal date: find recordings by the date of the rehearsal.

## First slice
List manually selected local recordings by rehearsal date.

## Constraints
- TypeScript, as the README specifies and the human confirmed.
- Browser UI, as the README specifies and the human confirmed.
- Recording files stay local.

## Out of scope
- Cloud upload: recordings are not sent anywhere.
- Audio editing: recordings are not changed.

## Open questions
- How should recordings without a date be shown?
